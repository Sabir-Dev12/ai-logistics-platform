# LogisticsReference rollout

The existing frontend is React 18.3.1/Vite 5.4, with Tailwind 3 and component CSS. Shared tokens are defined in src/design-system/tokens.json and generated by npm run tokens. The existing dashboard uses Recharts and react-grid-layout; existing Card, Button, Input, Select, Table, Badge, Alert, Modal and layout components were reused.

## Chosen reference

The user explicitly chose the bundled dark screenshots over DESIGN.md’s contradictory light palette. The homepage image’s most common pixel is RGB(8,9,10), and its principal text is RGB(247,248,248). These map to #08090a and #f7f8f8. The skill’s dark border and violet accent values were reused. Inter Variable and Berkeley Mono are served locally from the supplied skill assets. No remote font dependency remains.

Dashboard was styled and verified first on desktop/mobile, including its period filter. Shared styling was then extended to the existing application pages, forms, dialogs, chat and login. Services, repositories, business calculations, endpoint paths, authentication, SignalR and backend code were not modified. No new application components, routes, dependencies or pages were introduced.

## Changed files

- src/design-system/tokens.json — charcoal palette, typography, spacing, radii, elevation and layer values.
- src/design-system/tokens.css — generated variables (npm run tokens).
- src/index.css — local font faces and global baseline.
- src/theme/dark.css — dashboard, shell and shared component treatment matching the selected reference.
- src/theme/reference-pages.css — existing page headers, forms, chat, login and home integration.
- src/main.jsx — imports the shared page theme.
- public/fonts/logistics-reference/InterVariable-100.woff2 — supplied font asset.
- public/fonts/logistics-reference/BerkeleyMono-100.woff2 — supplied font asset.
- DESIGN-REFERENCE.md — this record.

## Intentional visual differences

The reference is a Linear marketing site, while this is an authenticated logistics application. Logistics branding, operational navigation, tables, filters, dashboard widgets and controls are retained rather than replacing them with marketing copy, Linear branding or decorative product mockups. Dashboard titles and panels use the reference hierarchy adapted to application density. Existing grid breakpoints and drag/resize behavior are preserved.

The home background video and its existing pause control remain functional but are visually subdued, with decorative blue glows removed. Marketing scroll choreography and product illustrations are not replicated. Other pages inherit the shared system; their business-specific layouts and information density remain intact.

## Verification

Frontend build, token consistency and the existing functional regression suite are run. Browser inspection uses isolated presentation fixtures, never production route mocks or changed API wiring. The dashboard, Clients, Bookings, AI Agent and login are sampled, including mobile dialog/layout checks. No authenticated live API or database operation is performed for visual QA. Existing optional live tests remain skipped.
